# Импорт Русско-лакского школьного словаря 1958

Источник: [lakkumaz.narod.ru](https://lakkumaz.narod.ru/orus_mazral_va_lakku_mazral_shkolalul_slovar.html)  
~14 500 статей, направление в источнике: **русский → лакский**.

В приложении учим **лакский → русский** (`lemma` = лак., `translation` = рус.).  
Импорт не копирует статью целиком — режет её на **учебные атомы**.

## Принцип

Одна карточка = **одно лакское слово (основное)** + **один русский смысл**.

- В списке словаря и в SRS — только `translation_priority = 1`.
- Синонимы (`priority ≥ 2`) — на обороте / в детали слова.
- Разные значения одной русской леммы — **разные** `synonym_group_id` (`грязь#1`, `грязь#2`).
- Омонимы (`Коса 1` / `Коса 2`) — тоже разные группы (`коса#1`, `коса#2`).

Коллекции: `slovar-1958-{буква}` по **первой букве русского** заголовка, `kind = alphabet`.

## Схема разбора статьи

```text
[заголовок] [омоним N?] [грамматика…] [1) 2) …] [идиомы — …] [примеры]
     │            │           │            │           │
     ▼            ▼           ▼            ▼           ▼
 translation   #N в group  gender/aspect  lemma+syn   phrase / example
                             / part_of_speech
```

## Маппинг полей

| Из словаря | В БД | Примечание |
|---|---|---|
| Русский заголовок (без ударения) | `translation` | |
| Первое короткое лакское слово в смысле | `lemma` | то, что учим |
| Остальные лакские через запятую | те же `translation` + `synonym_group_id`, `priority` 2, 3… | |
| `м` / `ж` / `ср` | `gender` | только существительные |
| `сов.` / `несов.` / `однокр.` | `verb_aspect` | |
| POS-пометы | `part_of_speech` | нормализация ниже |
| `бахх.` / `дахх.` / `устар.` / `собир.` | `notes` | переносное — лучше отдельная группа |
| `мн. нет`, `ед. нет`, `мн. донья` | `notes` | не отдельные колонки |
| Текст в скобках `(кIиз)` | `notes` или synonym с низким priority | |
| Идиома / оборот после `—` | `word_type = phrase` или `word_examples` | не в SRS как слово |
| Длинная дефиниция (>~4 слов) | `notes` | **не** `lemma` |

### Нормализация `part_of_speech`

| В источнике | У нас |
|---|---|
| `м` / `ж` / `ср` (без прил. и т.п.) | `Сущ.` |
| `сов.` / `несов.` / `однокр.` | `Глаг.` |
| `прил.` | `Прил.` |
| `нареч.` | `Нареч.` |
| `предлог` / `предл.` | `Предл.` |
| `союз` / `мест.` / `межд.` / `числ.` | кратко, как в словаре |

## Правила парсера

1. Заголовок → `translation` (снять ударения: `а́` → `а`).
2. Цифра омонима `N.` → суффикс `#N` в `synonym_group_id`.
3. `1) 2) 3)` → отдельные группы `#1`, `#2`, …
4. Список через запятую внутри одного значения → synonyms, порядок = priority.
5. `бахх.` / `дахх.` → `notes: "перен."`; по возможности отдельная группа, не синоним прямого смысла.
6. После `—` (без номера смысла) → phrase / example.
7. Lemma = короткий лексический кусок (1–4 слова).
   - 3–4 слова оставляем, если это похоже на лакскую глоссу (глагол на *-тIун*, *-ришлан*, редупликация `кьутI-кьутI` и т.п.).
   - Иначе длинный кусок → `notes` (описательная дефиниция, как у «адрес»).
   - Двусловные ≥ 22 символов без «глагольности» тоже часто дефиниция.
8. `сов., … несов.` в одной строке (MVP): одна группа по сов. форме; несов. русскую лемму — в `notes` (`тж. добавлять`).
9. `сов. и несов.` → `notes`, `verb_aspect` можно `null` или `сов.`.
10. Несколько POS в одной статье (`а` = союз / частица / межд.) → **отдельные группы**.

## Примеры

### Простое сущ.

`абажу́р м. абажур, лампалул шар.`

| lemma | translation | gender | priority | group |
|---|---|---|---|---|
| абажур | абажур | м | 1 | абажур |
| лампалул шар | абажур | м | 2 | абажур |

### Несколько значений + идиома

`грязь ж. 1) кьяркьи, гьагъ, кьюнув; 2) чапалшиву…; забросать грязью — …`

- `кьяркьи` / `гьагъ` / `кьюнув` → группа `грязь#1`
- `чапалшиву`… → группа `грязь#2`
- идиома → `phrase`

### Омонимы

`Коса 1. ж. хIаллу` / `Коса 2. ж. чIиникI.` → группы `коса#1`, `коса#2`.

`знать 1. несов. …` / `знать 2. … ж. …` → разные POS и разные группы.

### Глагол

`доба́вить сов., добавля́ть несов. ххи буллан, ххи бан.`

| lemma | translation | aspect | priority | notes |
|---|---|---|---|---|
| ххи буллан | добавить | сов. | 1 | тж. добавлять (несов.) |
| ххи бан | добавить | сов. | 2 | |

`бежа́ть несов. лихъан, лечан.` → aspect `несов.`, priority 1/2.

### Предлог

`для предлог щин; ссан; для кого — щин; …`

- SRS: `щин` (priority 1), `ссан` (2)
- обороты после `—` → phrase / examples

### Переносное

`гря́зный прил. 1) чапалсса…; 2) бахх. мурдалсса…`  
→ `грязный#1` и `грязный#2` с `notes: "перен."` у второго.

### Заимствование + дефиниция

`а́дрес м. адрес; 1) чагъарданул конвертрай…`

- lemma: `адрес` (короткое слово)
- длинные `1) 2)` → `notes`, не карточки

### Мн.ч. / ед. нет

`дно мн. донья, ср. чIан …` → lemma `чIан`, gender `ср`, notes `мн. донья; …`

## Фазы импорта

| Фаза | Что грузим |
|---|---|
| **1 — ядро** | lemma, translation, gender, verb_aspect, POS, synonym_group + priority, notes (`перен.` / устар.), коллекции по буквам |
| **2** | examples, idioms → phrases |
| **3 (позже)** | полные мн.ч., тонкая грамматика, ручная чистка OCR |

## Что не импортируем

- Предисловие, титул, список сокращений как записи словаря
- Сырую строку статьи целиком в одну карточку
- Все значения одной кучей на одну SRS-карточку
- Русский заголовок как `lemma` (ломает направление учёбы)

## UX после импорта

- Список / алфавит «как в словаре»: русская буква → набор `slovar-1958-*`
- Деталь слова: род/вид, пометы, синонимы, фразы
- Повторение: только `priority = 1`; синонимы — подсказка на обороте

## Код и запуск

| Файл | Назначение |
|---|---|
| `src/lib/import/slovar1958.ts` | Разбор одной статьи → учебные записи |
| `src/lib/import/slovar1958.test.ts` | Примеры из этой спеки |
| `parse/run_slovar_1958.ts` | HTML → `parse/slovar_1958.json` / импорт в БД |

```bash
npm test -- src/lib/import/slovar1958.test.ts

# скачать страницу, разобрать, сохранить JSON
npm run parse:1958 -- --dry-run

# из локального HTML
npm run parse:1958 -- --from-file path/to.html --dry-run

# залить в PostgreSQL (нужен DATABASE_URL)
npm run parse:1958 -- --direct
```

Коллекции создаются со `kind = alphabet`, slug `slovar-1958-{буква}`.
