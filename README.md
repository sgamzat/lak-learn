# LAK Learn - Образовательная платформа

Платформа для обучения с использованием современных веб-технологий.

## 📋 Описание проекта

LAK Learn — это образовательное приложение с разделением на фронтенд и бэкенд, использующее PostgreSQL в качестве базы данных. Проект включает в себя:

- **Frontend** — клиентская часть с интерфейсом для пользователей и административной панелью
- **Backend** — API сервер на Node.js для обработки запросов
- **Database** — PostgreSQL база данных для хранения информации

## 🚀 Быстрый старт

### Предварительные требования

- [Docker](https://www.docker.com/) (версия 20.10+)
- [Docker Compose](https://docs.docker.com/compose/) (версия 2.0+)
- Веб-браузер (Chrome, Firefox, Safari, Edge)

### Установка и запуск

1. **Клонируйте репозиторий и перейдите в директорию проекта:**
   ```bash
   cd lak-learn
   ```

2. **Настройте переменные окружения:**
   
   Отредактируйте файл `.env` и укажите необходимые значения:
   ```
   DB_USER=your_username
   DB_PASSWORD=your_password
   DB_NAME=lak_learn
   JWT_SECRET=your_secret_key
   ```

3. **Запустите весь стек (БД + Бэкенд):**
   ```bash
   docker-compose up -d
   ```

4. **Проверьте статус контейнеров:**
   ```bash
   docker-compose ps
   ```

5. **Просмотр логов:**
   ```bash
   # Логи бэкенда
   docker-compose logs -f backend
   
   # Логи базы данных
   docker-compose logs -f postgres
   ```

6. **Запустите фронтенд:**
   
   **Вариант 1:** Откройте `frontend/index.html` напрямую в браузере
   
   **Вариант 2:** Запустите локальный веб-сервер:
   ```bash
   cd frontend
   python3 -m http.server 8080
   ```
   Затем откройте в браузере: [http://localhost:8080](http://localhost:8080)

## 🔧 Доступные сервисы

| Сервис | Порт | Описание |
|--------|------|----------|
| Backend API | 3000 | REST API сервер |
| PostgreSQL | 5432 | База данных |
| Frontend | 8080 | Веб-интерфейс (при запуске локального сервера) |

## 📦 Основные команды

```bash
# Запуск всех сервисов
docker-compose up -d

# Остановка всех сервисов
docker-compose down

# Перезапуск конкретного сервиса
docker-compose restart backend

# Просмотр логов
docker-compose logs -f [service_name]

# Сборка заново
docker-compose build

# Очистка (удаление контейнеров, сетей и томов)
docker-compose down -v
```

## 🔐 Безопасность

- Не коммитьте файл `.env` в репозиторий
- Используйте сложные пароли для базы данных
- Храните JWT_SECRET в секрете

## 🐛 Решение проблем

### Контейнер не запускается
```bash
# Проверьте логи
docker-compose logs backend

# Пересоберите образ
docker-compose build --no-cache
```

### Ошибки подключения к БД
- Убедитесь, что файл `.env` заполнен корректно
- Проверьте, что порт 5432 не занят другим сервисом
- Дождитесь полной инициализации PostgreSQL перед запуском бэкенда

### Проблемы с фронтендом
- Проверьте консоль браузера (F12) на наличие ошибок
- Убедитесь, что бэкенд доступен на порту 3000
